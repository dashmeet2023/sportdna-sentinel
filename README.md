# 🧬 SportDNA  
Self-Tracing Anti-Piracy Intelligence for Sports Media  

Built with Antigravity · Deployed on Google Cloud · Powered by Gemini 3.1 Pro  

---

## 🚀 Overview  
SportDNA is an AI-powered anti-piracy platform that embeds a perceptual fingerprint ("DNA") into sports media.  
It detects edited and redistributed pirated content across platforms in real time and initiates automated takedowns.

---

## ⚠️ Problem  
- Sports leagues lose $28B+ annually due to piracy  
- DMCA takedowns take 6–48 hours  
- Viral clips spread before action  
- Existing tools fail against edited content  
- No unified real-time detection system  

---

## 💡 Solution  
- 256-dimensional perceptual DNA fingerprints  
- Edit-resilient matching  
- AI-powered threat analysis  
- Automated DMCA pipeline  
- Real-time analytics  

---

## ✨ Features  
- Self-tracing media (no watermark needed)  
- Detection across TikTok, YouTube, Telegram, X  
- Gemini AI Guardian Agent  
- Propagation prediction  

---

## 🏗️ Architecture  

Frontend → React 19 (TanStack Start)  
Backend → Cloud Run  
AI → Gemini via Vertex AI  
Database → PostgreSQL (Cloud SQL)  
Storage → Google Cloud Storage  

Pipeline:  
Upload → DNA Generation → Matching → AI Analysis → DMCA  

---

## 🔄 Process Flow  
1. Upload footage  
2. Generate DNA  
3. Store in registry  
4. Crawl platforms  
5. Match using cosine similarity  
6. AI threat analysis  
7. Auto-DMCA  
8. Analytics dashboard
